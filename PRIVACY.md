# Privacy

Kinemotif collects nothing.

- **No analytics.** No Google Analytics, no Plausible, no counters, no pixels.
- **No cookies.** The site sets none.
- **No network calls.** The studio loads no fonts, no scripts, no images and no telemetry. Once
  the page is open, it works with the network switched off.
- **No accounts.** There is nothing to sign up for and no way to identify you.

## What is stored on your device

One key in `localStorage`, `kinemotif.project.v1`, holding the project you are editing, so a
refresh does not lose your work. Clearing site data removes it.

If you export a show, your browser writes a file to your downloads folder. That file is yours;
it contains only the show you made.

## Fonts and rendering

Every style uses fonts already installed on your system. Nothing is fetched from a font CDN,
which also means no third party sees that you visited.

## Hosting

The live demo is served by GitHub Pages. GitHub's own privacy policy applies to the HTTP request
that fetches the page — the same as any other static site. The page itself then runs offline.
